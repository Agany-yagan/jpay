## 🚀 What is JPay?

JPay V5 is a modern Till payment system for Kenyan businesses. Accept payments via Till Number, QR code, and STK Push.

## ✨ Features

- ✅ Till Number Payments
- ✅ M-Pesa STK Push
- ✅ QR Code Generation
- ✅ Real-time Dashboard
- ✅ Transaction History
- ✅ SMS Receipts

## 🛠️ Tech Stack

- Frontend: HTML / CSS / JS
- Backend: Node.js / PHP
- Database: MySQL / Firebase
- Payments: M-Pesa Daraja API
